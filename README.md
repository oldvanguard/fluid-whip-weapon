# FLUID → WHIP → WEAPON

A mobile-first movement operating system combining adaptive physical development with a progressively unlocked self-defense curriculum.

## Current vertical slice

- Functional mobile-first dashboard
- Persistent browser progress via localStorage
- FLUID I: Restore training session
- DAREBEE-inspired glanceable training card UX
- BODY competency dashboard
- Movement Passport / competency gates
- FLOW prompt lab
- Range continuum foundation
- Locked WHIP and WEAPON stages ready for expansion
- Data-driven movement records designed for future image, animation, range, prerequisite, and branching metadata

## System doctrine

The shared movement engine is:

`ROOT → SHIFT → COIL → CHAIN → EXPRESS → RECOVER → FLOW`

Training progression is competency-based rather than calendar-based.

## Run

No build step is required for this initial vertical slice. Open `index.html` in a browser or serve the repository as static files.

## Architecture direction

The current dependency-light implementation deliberately validates the UX and domain model first. Later production phases can introduce authentication/cloud persistence, installable PWA support, structured content storage, richer assessment logic, generated visual assets, audio prompts, camera-assisted review, and the full WHIP/WEAPON/REDIRECT decision graph without discarding the underlying domain concepts.

## Safety design

The app treats sharp/new pain as a stop signal rather than a progression challenge. Physical readiness and regression/substitution logic will be expanded as the training engine grows.
